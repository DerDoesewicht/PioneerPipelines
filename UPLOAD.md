# Uploading the documentation and screenshots

1. Extract this package. Upload the contents of the GitHub folder to the root of DerDoesewicht/PioneerPipelines on the main branch. Preserve the docs/assets directory structure.
2. Commit the updated README.md, CHANGELOG.md, MODPAGE.md, LISTING.md and docs folder. GitHub Pages can publish from main /docs.
3. Once the images are available on GitHub, open the mod portal page and select Edit.
4. Replace the full description with the contents of MODPAGE.md. Its absolute image URLs point to the repository above, so the images can render outside GitHub.
5. Check that the GitHub-hosted images appear in the preview, then save the page. No separate image upload to the mod portal is needed.
6. The two pressurizer images document the unchanged vanilla building and its known display limitation; they are not new Pioneer buildings.

This package updates documentation and screenshots only. No mod rebuild is required. It does not publish anything automatically.
