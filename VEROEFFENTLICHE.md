# Publishing instructions

1. Upload the contents of this GitHub folder to the repository root.
2. Use README.md for the repository overview and MODPAGE.md for the mod portal description.
3. Configure GitHub Pages to publish the docs folder on the main branch.
4. Use LISTING.md for listing metadata and CHANGELOG.md for version 1.1.0 release notes.
5. Upload the compiled Alpakit mod ZIP to the mod portal. This documentation folder is not an installable mod.
6. Update the download link once the actual release URL is available.

Choose a source license before publishing source code; do not upload third-party game or SDK files.
